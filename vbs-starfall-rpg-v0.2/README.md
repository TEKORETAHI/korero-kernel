# VBS STARFALL v0.2

Playtest-driven update based on the first VBS Core Lens report.

Changes: automatic forward cruise, actual-distance tracking, gentler dynamic enemy cap, slower early enemy fire, respawn protection, persistent objectives across level-ups, escalating waves, a boss every fifth wave, boss spread-fire and rewards, richer loot, combo scoring, stronger shock-ring explosions, wave persistence, expanded Core Lens telemetry, and real simulated NOR SET/RESET transition counting.

The VBS layer mirrors control/game state through 256 virtual latches built from 512 NOR gates. Three.js remains the rendering and high-level simulation layer.
